# media-enhance

## 功能

### 播放控制
- 接管 Obsidian 内嵌视频/音频，使用原生控制条 + 右上角悬浮工具条
- 在链接里指定片段起止时间：从第几秒开始、到什么时候结束（播到结尾用 `e`）
- 片段循环、自动播放、静音
- 播放倍速：按链接设置，也可在播放器上随时调整（含自定义数值）
- 范围锁定：点击/拖动进度条越界，松手后自动吸附回起点或终点，不允许播放到片段范围之外（可在设置中关闭）
- ⏮ 一键精确回到片段起点（不受进度条像素精度限制）

### 时间戳
- 播放器右键 →「复制当前时间戳」，得到形如 `[[教程.mp4#t=42.5|00:42.5]]` 的链接，粘贴到笔记即可
- 点击时间戳定位到对应位置：
  - 阅读视图：直接点击
  - 实时预览：`Ctrl/Cmd + 点击`（普通点击仍是编辑）
  - 视频就在当前笔记：精确定位并高亮、滚动到播放器
  - 视频在其它标签页：自动切换过去并定位
  - 视频未打开：弹出播放器窗口并停留在对应时间

### 编辑与设置
- 播放器右键 →「编辑片段参数」：可视化修改起始时间、结束时间、倍速、循环、自动播放，支持「填入当前播放位置」
- 播放器右键 →「播放倍速」子菜单，或工具条上的倍速按钮
- 设置页：
  - 默认播放倍速（链接中没有 `speed=` 时使用）
  - 记住手动调整的倍速
  - 锁定片段起止范围（开关）

## 链接语法

| 写法 | 效果 |
| --- | --- |
| `![[教程.mp4]]` | 普通嵌入，工具条可用 |
| `![[教程.mp4#t=10]]` | 从 10 秒开始，播到结尾 |
| `![[教程.mp4#t=00:10,e]]` | 同上（`e` 表示播到结尾） |
| `![[教程.mp4#t=10,20]]` | 只播 10s–20s，到 20s 精确暂停 |
| `![[教程.mp4#t=,30]]` | 从开头播到 30s |
| `![[教程.mp4#t=01:00,01:30&speed=1.5]]` | 片段 + 1.5 倍速 |
| `![[教程.mp4#t=10,e&loop]]` | 片段循环 |
| `![[教程.mp4#t=10&autoplay&mute]]` | 自动播放并静音 |

- 时间格式：秒（`10`、`10.5`）、`MM:SS`、`HH:MM:SS`
- 支持属性：`speed=`、`loop`、`autoplay`、`mute`（以及对应 `no_*` 关闭写法）；未知属性编辑时会原样保留

## 安装

1. 将本目录（`main.js`、`manifest.json`、`styles.css`）放到 vault 的 `.obsidian/plugins/media-enhance/`
2. 重启 Obsidian，在「设置 → 第三方插件」中启用 media-enhance

## 开发

- 源码即 `main.js`（无构建步骤），修改后把文件复制到插件的 `main.js`
- 在 Obsidian 里禁用再启用插件即可加载新代码；插件会自动重建笔记中已渲染的旧播放器，无需重启
